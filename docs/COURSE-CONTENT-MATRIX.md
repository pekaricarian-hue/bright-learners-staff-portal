# Bright Learners Provincial Course Content Matrix

Status: Working curriculum specification

Authority order:

1. Current provincial legislation and regulation
2. Current provincial health-authority direction
3. Current licensing guidance
4. Written location-specific direction
5. Bright Learners policy and orientation

Every finished lesson slide and quiz question must identify the issuing authority,
document title, version/date, PDF page, printed section or regulation when
available, and the date the source was last verified. Verbal guidance is never
presented as legislation or a written public-health requirement.

## Quiz rules

- Questions are scenario-based where possible.
- Every question records the correct answer, plain-language explanation, source,
  and exact remediation slide.
- A module is complete only at 100%.
- A failed attempt shows only the missed concepts and provides a direct button
  to each relevant slide.
- Every attempt stores answers, score, time, module version and course version.
- Question order and option order may be randomized in production without
  changing the source or correct answer.

## Resume and version rules

- Current module, current slide, completed modules and quiz attempts are stored
  per user and province.
- Leaving the page does not erase progress.
- A completed module remains reviewable.
- If a regulated lesson changes materially, administration publishes a new
  course version and assigns the required refresher rather than silently
  changing a historical completion record.
