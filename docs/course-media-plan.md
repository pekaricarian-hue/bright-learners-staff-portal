# Bright Learners course media plan

This inventory tracks lesson visuals that are still required. “Real” means Bright Learners should photograph or record its actual environment or procedure. “Illustration” means an original, policy-aligned training graphic can be generated without representing a real centre.

## Completed example

- Saskatchewan Module 3, “When to wash”: six-step handwashing illustration showing wet, soap, scrub all surfaces, fingertips/thumbs, rinse and dry. File: `public/course-media/handwashing-steps-notion.png`.

## Recording standards

- Landscape 16:9 video, 1080p minimum.
- Film the actual procedure from start to finish; do not skip steps in the edit.
- No visible child names, attendance sheets, medication labels or other personal information.
- Obtain required consent before showing any identifiable child.
- Use staged staff-only demonstrations whenever privacy or consent is uncertain.
- Keep spoken instructions consistent with the current posted procedure and official provincial requirements.
